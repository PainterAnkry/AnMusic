## AnMusic v3.3.7

基于 WPF 的桌面音乐播放器：本地曲库 + 多音源在线搜索（网易云 / QQ音乐 / B站），
支持 MusicFree 兼容 `.js` 音源插件扩展。

### 下载说明

| 文件 | 说明 |
|---|---|
| `AnMusic-Setup-3.3.7.exe` | 安装版（推荐）：中文向导、开始菜单/桌面快捷方式、完整卸载器，**无需管理员权限** |
| `AnMusic-Portable-3.3.7.exe` | 便携版：免安装单文件，下载后直接运行 |

两个版本均**自包含 .NET 10 运行时**，目标机器无需安装任何依赖（Windows 10/11 x64）。

### 本版新增（v3.3.7）

- 🔍 **搜索结果分类**：搜索页顶部新增 综合 / 单曲 / 歌手 / 专辑 四个页签。
  **综合**页会是「歌手卡 + 专辑卡一行 + 单曲列表」的组合（和网易云一致），
  单曲页只看列表，歌手/专辑页是卡片网格
- 🎤 **歌手页**：列表里点歌手名（或搜索结果点歌手卡）进入——圆形大头像、大号歌手名、
  `单曲 N 首 · 专辑 M 组`、**▶ 播放全部**，下面分 `歌曲` / `专辑` 两个页签
- 💿 **专辑页**：点专辑名/专辑卡进入——方形圆角封面、专辑名、`歌手 · N 首`、**▶ 播放全部** + 曲目列表
  （右键菜单里播放/下一首/收藏/下载/加入歌单/查看歌手全部可用）；返回键原路退回
- 📄 **打开本地文件**：本地歌曲标题栏按钮、列表右键菜单、下载管理页都有，
  可一次选多个本地音频文件加入「本地歌曲」；**路径会记住，重扫目录后仍在**
- 🎨 **新应用图标**：换成新的 AnMusic 蓝底白字 logo（多尺寸 ico，标题栏/任务栏/安装包同步）

### 本次修复（v3.3.1）

- ⬇ **修复在线歌曲「听过后就下载不了」**：在线搜索到的歌播放一次后，再点「下载到本地」
  会弹出「该曲目已是本地文件，无需下载」，实际上并没有下载。
  根因是播放时生成的**缓冲文件**被写进了表示"本地音乐文件"的字段里，
  下载判断看到磁盘上确实有那个文件，就把"听过一次"当成了"已下载"。
  现在缓冲单独存放，只有真正的本地音乐才会提示无需下载
  - 顺带修复：网易云 / QQ 音乐选择「无损」下载时，可能拿到刚才在线试听时缓存的 320k 文件
  - 顺带修复：清理过缓冲缓存后，正在播放的在线歌曲会被判为"文件不存在"，现在会自动重新缓冲
  - 顺带修复：「一起听」房主分享的在线歌曲会把房主机器上的缓存路径发给成员，导致成员端播放失败

### 升级说明

覆盖安装即可。用户数据（歌单 / 收藏 / 设置等）保存在 `%AppData%\AnMusic`，
旧版本位于 `%LocalAppData%\AnMusic` 的数据会在首次启动时自动迁移，不受影响。
