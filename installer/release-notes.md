## AnMusic v3.0.1

基于 WPF 的桌面音乐播放器：本地曲库 + 多音源在线搜索（网易云 / QQ音乐 / B站），
支持 MusicFree 兼容 `.js` 音源插件扩展。

### 下载说明

| 文件 | 说明 |
|---|---|
| `AnMusic-Setup-3.0.1.exe` | 安装版（推荐）：中文向导、开始菜单/桌面快捷方式、完整卸载器，**无需管理员权限** |
| `AnMusic-Portable-3.0.1.exe` | 便携版：免安装单文件，下载后直接运行 |

两个版本均**自包含 .NET 10 运行时**，目标机器无需安装任何依赖（Windows 10/11 x64）。

### 本次修复（v3.0.1）

- 🎲 **修复开启随机播放后可能直接停播**：随机序列此前把当前曲目排在任意位置，
  若恰好排在末尾，按「下一首」会被判为「没有下一首」而停止播放；
  现改为把当前曲目置于新序列首位，开启随机后按下一首会依次走完其余歌曲
- 补充随机播放相关单元测试（78 项全部通过，连续多轮运行稳定）

### 本版新增

- ⌨️ **键盘快捷键 + 快捷键设置**：16 个可自定义动作（播放/暂停、切歌、音量、静音、快进快退、
  播放模式、收藏、歌词页、桌面歌词、迷你卡片、聚焦搜索、设置、显示/隐藏主窗口…）。
  设置页「快捷键」分区可逐项改键（Esc 取消、Delete 清除）、自动检测按键冲突，
  并支持勾选**全局热键**——在其他程序里也生效，被系统或其他软件占用时会明确提示
- 🎨 **皮肤系统**：新增深空蓝 / 午夜紫 / 护眼绿 / 暖阳橙 / 樱雾粉 5 套完整配色（共 7 套），
  标题栏 🎨 按钮一键预览切换，强调色可在此基础上单独调整
- 📻 **迷你悬浮卡片播放器**：独立置顶小窗，只保留封面 / 歌名歌手 / 收藏 / 音量 / 播放列表 /
  进度条等核心元素，可拖动并记忆位置；开启时主窗口自动最小化
- 📃 **设置页分类分页**：左侧「通用 / 外观 / 播放 / 歌词 / 快捷键 / 音源 / 关于」，搜索框跨分类定位
- 🔗 **分享当前歌曲**：播放条「⋯ 更多」菜单一键复制歌曲信息与原站链接
- 🌤 **时段问候**：按早/中/晚在内容区标题旁展示小问候
- 🖥 **桌面歌词打磨**：三行显示（前后行可点击跳转）、锁定模式防误触、滚轮调字号/行距/背景浓度、位置记忆
- 🪟 **空状态引导**：列表为空时按视图给出引导文案（音乐库、搜索、歌单、排行榜、电台等）

### 本版优化

- 🔒 **修复设置静默丢失**：窗口位置用 `NaN` 表示“未设置”，此前会让整次保存抛异常并被吞掉，
  导致主题/音量等设置改了却不落盘；现已正常读写，保存失败也会写入 `error.log`
- 🧹 **封面缓存自动清理**：新增 256 MB 上限，超限按最久未用淘汰（此前只增不减）
- 💾 **在线歌词落盘缓存**：歌词改走本地缓存，断网或被限流时也能显示已获取过的歌词
- 🌐 **网络统一出口 + 代理设置**：所有请求集中管理 UA/超时，设置页可填代理地址
  （如 `http://127.0.0.1:7890`，留空跟随系统），音源 / 更新检查 / 歌词 / 插件下载同时生效
- 💬 **错误提示友好化**：不再把技术异常直接抛给用户，改为一句人话，完整堆栈只进日志
- ⚡ **播放更稳**：音频回调线程改用异步调度，避免 UI 繁忙时反压音频线程造成卡顿
- 🐛 修复「打开设置」默认键位写法错误导致该快捷键失效
- 🧪 **补充 76 项单元测试**：覆盖快捷键解析与默认键位、LRC 歌词解析、播放队列四种模式、
  缓存淘汰与代理配置，纳入日常回归
- 🧩 代码结构：`MainViewModel` 按职责拆分为 partial 文件，便于后续维护

### 升级说明

覆盖安装即可。用户数据（歌单 / 收藏 / 设置等）保存在 `%AppData%\AnMusic`，
旧版本位于 `%LocalAppData%\AnMusic` 的数据会在首次启动时自动迁移，不受影响。
