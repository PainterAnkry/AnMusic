## AnMusic v2.0.1 修复版

基于 WPF 的桌面音乐播放器：本地曲库 + 多音源在线搜索（网易云 / QQ音乐 / B站），
支持 MusicFree 兼容 `.js` 音源插件扩展。

### 下载说明

| 文件 | 说明 |
|---|---|
| `AnMusic-Setup-2.0.1.exe` | 安装版（推荐）：中文向导、开始菜单/桌面快捷方式、完整卸载器，**无需管理员权限** |
| `AnMusic-Portable-2.0.1.exe` | 便携版：免安装单文件，下载后直接运行 |

两个版本均**自包含 .NET 10 运行时**，目标机器无需安装任何依赖（Windows 10/11 x64）。

### 本次修复

- **修复歌曲播完不自动切歌**：顺序 / 列表循环 / 单曲循环 / 随机四种播放模式全面恢复
  （根因：引擎用“读取位置≥文件长度”判断播完，mp3/flac/m4a 等压缩格式末帧常差几个字节被误判为手动停止，导致 TrackEnded 不触发；现改为按“非手动停止”判定自然播完）
- 队列播完停止后再按播放（含媒体键）可重新播放当前曲目
- 本地音乐库扫描补录 `.m4s` 文件（B站下载的音频此前扫不出来）
- 自动切歌流程统一回 UI 线程，避免队列与界面并发竞争

### 升级说明

覆盖安装即可，用户数据（歌单/收藏/设置等）保存在 `%LocalAppData%\AnMusic`，不受影响。
