## AnMusic v3.3.4

基于 WPF 的桌面音乐播放器：本地曲库 + 多音源在线搜索（网易云 / QQ音乐 / B站），
支持 MusicFree 兼容 `.js` 音源插件扩展。

### 下载说明

| 文件 | 说明 |
|---|---|
| `AnMusic-Setup-3.3.4.exe` | 安装版（推荐）：中文向导、开始菜单/桌面快捷方式、完整卸载器，**无需管理员权限** |
| `AnMusic-Portable-3.3.4.exe` | 便携版：免安装单文件，下载后直接运行 |

两个版本均**自包含 .NET 10 运行时**，目标机器无需安装任何依赖（Windows 10/11 x64）。

### 本次修复（v3.3.4）

- 🎤 **修复切歌后歌词不换**：自动切歌 / 上一首下一首之后，歌词还停在上一条。
  根因是歌词只在"点歌播放"的几条路径里装载，其余切歌路径绕过了它；
  现在统一挂在"曲目变化"这一个入口上，所有切歌方式（含自动切歌）歌词都会同步更换；
  同一首重播（单曲循环）不会重复装载，避免歌词闪一下
- 🎨 **修复深色皮肤下的一条白带**：强调色的"浅色底"是给浅色主题用的近白色，
  深色皮肤下套用后，状态提示条 / 选中项底色会发白（主页标题下那条横线就是它）。
  现在深色皮肤改为"向皮肤底色靠拢的强调色浅染"；另外状态提示条**没有内容时整条收起**，
  不再白占一行
- 🎨 **修复标题栏不随主题变化**：开启背景图后半透明逻辑把标题栏/视图标题行一起透明掉了，
  浅色壁纸透上来时深色皮肤的标题栏会变成浅色、文字糊掉；现在半透明只作用于内容区
- 🎨 **修复列表表头不随主题变化**：列表的列标题行用的是 WPF 默认控件外观（系统浅色），
  换皮肤也不变；现在统一换成主题底色 + 细分隔线，悬停/按下有反馈，整列可点排序
- 🔄 **滚动条换成主题圆角样式**：原来是系统默认的浅灰方块滚动条（换肤无效），
  现在是 10px 细轨 + 圆角滑块，颜色跟随皮肤（悬停变亮、拖动变强调色）

### 本次修复（v3.3.1）

- ⬇ **修复在线歌曲「听过后就下载不了」**：在线搜索到的歌播放一次后，再点「下载到本地」
  会弹出「该曲目已是本地文件，无需下载」，实际上并没有下载。
  根因是播放时生成的**缓冲文件**被写进了表示"本地音乐文件"的字段里，
  下载判断看到磁盘上确实有那个文件，就把"听过一次"当成了"已下载"。
  现在缓冲单独存放，只有真正的本地音乐才会提示无需下载
  - 顺带修复：网易云 / QQ 音乐选择「无损」下载时，可能拿到刚才在线试听时缓存的 320k 文件
  - 顺带修复：清理过缓冲缓存后，正在播放的在线歌曲会被判为"文件不存在"，现在会自动重新缓冲
  - 顺带修复：「一起听」房主分享的在线歌曲会把房主机器上的缓存路径发给成员，导致成员端播放失败

### 本版优化

- 🔒 **修复设置静默丢失**：窗口位置用 `NaN` 表示“未设置”，此前会让整次保存抛异常并被吞掉，
  导致主题/音量等设置改了却不落盘；现已正常读写，保存失败也会写入 `error.log`
- 🧹 **封面缓存自动清理**：新增 256 MB 上限，超限按最久未用淘汰（此前只增不减）
- 💾 **在线歌词落盘缓存**：歌词改走本地缓存，断网或被限流时也能显示已获取过的歌词
- 🌐 **网络统一出口 + 代理设置**：所有请求集中管理 UA/超时，设置页可填代理地址
  （如 `http://127.0.0.1:7890`，留空跟随系统），音源 / 更新检查 / 歌词 / 插件下载同时生效
- 💬 **错误提示友好化**：不再把技术异常直接抛给用户，改为一句人话，完整堆栈只进日志
- ⚡ **播放更稳**：音频回调线程改用异步调度，避免 UI 繁忙时反压音频线程造成卡顿
- 🐛 修复「打开设置」默认键位写法错误导致该快捷键失效
- 🧪 **补充单元测试（现 119 项）**：覆盖快捷键解析与默认键位、LRC 歌词解析、播放队列四种模式、
  缓存淘汰与代理配置，纳入日常回归
- 🧩 代码结构：`MainViewModel` 按职责拆分为 partial 文件，便于后续维护

### 升级说明

覆盖安装即可。用户数据（歌单 / 收藏 / 设置等）保存在 `%AppData%\AnMusic`，
旧版本位于 `%LocalAppData%\AnMusic` 的数据会在首次启动时自动迁移，不受影响。
